Manual Book & Panduan Penggunaan WarungPOS

Panduan lengkap langkah demi langkah pengoperasian aplikasi kasir POS offline untuk pemilik toko dan kasir.

1 BAB 1: Pengenalan & Persiapan Sistem

WarungPOS berjalan 100% secara offline di komputer/laptop Windows. Semua data tersimpan aman pada penyimpanan lokal toko Anda tanpa tergantung koneksi internet. Aplikasi ini memiliki proteksi Single Instance Lock untuk mencegah aplikasi terbuka ganda secara tidak sengaja.

Langkah Aktivasi Lisensi Aplikasi:

  1. Jalankan file Warung POS.exe.
  2. Salin Kode Hardware ID (HWID) yang tampil di halaman Aktivasi.
  3. Kirim HWID ke Sales/Support WhatsApp (+62895321742593) untuk mendapatkan Serial Key Aktivasi Permanen.
  4. Masukkan Serial Key lalu klik Aktivasi Sekarang.

2 BAB 2: Panduan Dashboard Utama & Notifikasi Stok

Dashboard utama menyajikan ringkasan grafik omset harian, keuntungan bersih (laba kotor), dan peringatan stok menipis secara otomatis.

Icon Lonceng Stok Menipis

Terletak di header atas sebelah profil user. Menampilkan badge merah jika ada produk dengan stok dasar ≤ 10 PCS atau habis (0).

4 Kartu KPI Harian & Laba Kotor

Menghitung Omset Hari Ini, Untung Bersih (Margin Laba Kotor), Total Nota Transaksi, dan Total Barang Terjual (PCS).

3 BAB 3: Master Data Produk & Multi-Satuan

Aplikasi mendukung fitur variasi multi-satuan per produk (misal: Pcs, Pack, Dus) lengkap dengan konversi otomatis.

Cara Mengedit Stok / Mengurangi Stok Barang:

Buka menu Data Produk → Klik Kelola pada produk target → Klik Edit pada variasi → Isi kolom Tambah Stok (Global/PCS) dengan angka minus (misal: -10) untuk mengurangi stok, atau angka positif untuk menambah stok.

4 BAB 4: Terminal Transaksi POS Kasir (Shortcut F5 & Enter)

Memproses penjualan belanja konsumen dengan sangat cepat kurang dari 1 detik.

Pintasan Keyboard: Tekan tombol F5 di mana saja untuk membuka POS Kasir. Tekan Enter pada modal pembayaran untuk langsung cetak struk tanpa perlu menggunakan mouse!

5 BAB 5: Riwayat Transaksi, Export Laporan & Void Nota

Memantau riwayat penjualan, mencetak ulang nota transaksi dengan watermark [ CETAK ULANG ], export laporan Excel & PDF, dan melakukan pembatalan nota (Void) khusus akun Admin.

Export Excel Multi-Sheet & Laporan PDF Resmi

Fitur Export Excel mengunduh file .xlsx multi-sheet yang memisahkan Tab Laporan Penjualan, Tab Laba Rugi, dan Tab Detail Item Terjual secara rapi.

6 BAB 6: Pengaturan Toko & 3 Template Struk Thermal

Mengatur Nama Toko, Alamat, Nomor HP, Ukuran Kertas (58mm / 80mm), dan pilihan 3 Template Struk Thermal: Klasik, Modern, & Minimalis yang ditenagai Zero-Delay C# Thermal Printing Engine.

7 BAB 7: Backup Database & Import Excel

Mendukung Backup 1-Klik ke file .db lokal serta Import data massal ribuan produk via template Excel.

8 BAB 8: Hak Akses Pengguna (Admin vs Kasir)

Aplikasi membatasi hak akses role Kasir agar tidak dapat mengubah harga, menghapus produk, melihat laporan laba bersih, atau membatalkan transaksi.

9 BAB 9: Troubleshooting & FAQ

TANYA Printer thermal tidak keluar kertas / tidak merespon?

Buka menu Pengaturan Toko → Pastikan nama printer yang dipilih pada dropdown sesuai dengan nama printer yang terinstall di Windows Driver.

TANYA Bagaimana jika komputer toko diganti atau rusak?

Ambil file backup .db Anda, install aplikasi di komputer baru, kirim HWID baru ke tim support WhatsApp (+62895321742593) untuk pemindahan lisensi, lalu restore file database Anda.
